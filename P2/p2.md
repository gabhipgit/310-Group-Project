# 4. Data Sources (flora)
## Source 1: PoetryDB
- Docs: https://github.com/thundercomb/poetrydb
- Used for: Action 3, finding poems that match the confirmed vibe words
- Key/limits: No key. No rate limit.
- Call: GET https://poetrydb.org/lines,poemcount/rain;3/title,author,lines,linecount
- Real response (trimmed):
  {"title": "Fragments", "author": "Alan Seeger",
   "lines": ["In that fair capital where Pleasure, crowned", ...],
   "linecount": "83"}
- Surprises:
  - Searching lines matches substrings: "rain" returned a poem that only contains "rainbow".
  - Common words like "rain", "night", "love" return 413 (over 500 matches).
  - Word  "nostalgia" return 404; while "energetic" returned only 3 poems.
  - Poems can be very long (83 lines) and contain empty lines.

## Source 2: Last.fm API
- Docs: https://www.last.fm/api/show/user.getRecentTracks
- Used for: Action 1, getting the user's recent songs.
- Key/limits: Free API key, stored in .env (LASTFM_API_KEY). No strict limit stated, but we should avoid many calls in a row.
- Call: GET https://ws.audioscrobbler.com/2.0/
  ?method=user.getrecenttracks&user=rj&api_key=KEY&format=json&limit=5
- Real response (trimmed):
  {"recenttracks": {"track": [
    {"name": "Somebody Told Me",
     "artist": {"#text": "The Killers"},
     "album": {"#text": "Hot Fuss"},
     "date": {"#text": "18 Nov 2026, 22:15"}}, ...]}}
- Surprises:
  - The artist name is under the key "#text", not "name".
  - No genre or mood info, only names, so the "vibe" must come from the LLM reading titles and artists.

## Source 3: Google Gemini API (LLM)
- Docs: https://ai.google.dev/gemini-api/docs
- Used for: Action 2, turning recent tracks into a descriptive, vibe sentence with 3 imagery words, which the user then confirms
- Key/limits: Free API key from Google AI Studio, stored in .env
  (GEMINI_API_KEY). Free tier does have rate limits.
- Call: client.models.generate_content(model="gemini-3.8-flash",
  contents=prompt), where the prompt includes 5 recent songs and
  asks for JSON only
- Real response:
  {"vibe": "A late-night, atmospheric blend of moody R&B and synth-pop
   driven by quiet longing, secret romance, and hypnotic stillness.",
   "words": ["neon", "smoke", "rain"]}
- Surprises:
  - gemini-2.5-flash returned 404 ("no longer available to new users"),
    so model names expire. We list models with client.models.list().
  - gemini-2.5-flash returned 404 ("no longer available to new users"),
    so model names expire. We list models with client.models.list().
  - gemini-3.8-flash returned 503 (high demand) on two tries;
  - gemini-3.5-flash is the only model that worked. 
  - Asking for concrete imagery words (not moods) gives words that can potentially be searched in PoetryDB.
