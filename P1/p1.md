# Concept 1: Tracks & Poetry 
Get recommended poems based off user's recent tracks. AI summarizes the vibe of the tracks, verifies vibe with the user, then returns poems that match vibe of user's recent listening. 

## Sketch

## Who it's for
This project would benefit music lovers  who are trying to get back into reading and need motivation. Specifically those who want a fun way to find short readings (poems) that they'd feel connected too.  

## Value Adds...
This adds value to the user by producing short form literature tailored by analyzing their recent listening data. It gives the user another way to learn about themselves, while expanding their literary world.  

## Data Used...
This project would collect user listener data with Last.Fm's API, as well as poetry data from the PoetryDB API. 

## Depth Item...
AI step with a human check

## Diagram User Flow + States

## AI Building pros and cons 
AI would be good at making this app quickly, but would be bad at summarizing a "vibe" based off of users recent listening- It would probably need a bit more prompting/explaination on what exactly the "vibe" part is going to be used for.

# Concept 2: Oppoetry 
User types a word to a bot in slack (or discord), and gets a random poem based on that word's antonym or closest antonym. 

## Sketch

## Who it's for
This project is for those who are looking to have some fun while on communication servers. Anyone who is bored and wants to read a poem that they're least expecting, or maybe for those trying to immerese themselves in a different perspective/world. Broadly, this project is for entertainment and amusement purposes for someone who uses a platform like slack.  

## Value Adds...
This adds value to the user by providing a source of creative entertainment that still feels productive (reading) and exploratory (not knowing what poem will be given). 

## Data Used...
This project would use poem data from PoetryDB's API and linguistic data from Merriam-Webster's Collegiate Thesaurus API. 

## Depth Item...
Lives in a channel

## Diagram User Flow + States


## AI Building pros and cons 
AI would be good at being able to use both API's to get an antonym based poem for the user, but would be bad making the design non-basic and interesting, especially for a chatbot, not a website.

# Concept 3: Bites & Beatz
A world map where the user can click on a country to get local recipes and a list of trending tracks for that country. 

## Sketch

## Who it's for
This project is for food and music lovers trying to expand their taste. Anyone who wants to learn more about what's going on outside of their small slice of the world in terms of tunes AND eats.

## Value Adds...
This adds value to the user by educating them about recipes from foods around the world and also what music is popular around the world, catagorized by country. 

## Data Used...
This project would use meal/recipe data from TheMealDB API and global trending music track data from the Last.FM API. 

## Depth Item...
Made for a place

## Diagram User Flow + States

## AI Building pros and cons 
AI would be good at getting the data from both APIs and combining the data by country, but on it's own, would be bad at verifying if the data is accurate/dealing with missing data.
